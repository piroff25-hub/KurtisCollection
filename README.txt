Annnnuu’s Closet
=================
A static, private fashion-discovery website built from the supplied 85 product links and 85 supplied product photos.

Files:
- index.html — complete responsive site
- images/ — supplied product photos, mapped 1-to-1 to products 1–85

Important:
- The site is NOT an ecommerce store.
- “Shop Original” opens the exact supplied product URL in a new tab.
- Product details that were not supplied/verified are intentionally not invented.
- Favorites persist in the browser via localStorage.

To use:
1. Unzip this folder.
2. Open index.html in a modern browser.
3. Upload the folder to any static host if you want to share it.
